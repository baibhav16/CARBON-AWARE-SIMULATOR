What this animation represents

The moving cyan packets represent sensor data travelling to the edge gateway. The gateway represents local AI inference. Green/orange paths represent commands sent to HVAC, water heating and EV charging. The cloud supplies forecast signals; the local edge node makes the immediate scheduling decision.

Research accuracy: This is an animated conceptual demonstrator with synthetic values and illustrative rule-based decisions.
